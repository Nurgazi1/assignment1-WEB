Overview of Godot Engine

Godot is a free, open-source game engine that makes creating 2D games intuitive and modular.

Core Engine Features

Using GDScript, developers can quickly structure scenes and handle physics calculations with minimal overhead.

  • Node-based scene composition
  • Built-in 2D physics engine
  • Dedicated GDScript language

  2. Create a new 2D scene node
